# 🧬 생쥐 이자(Pancreas) 단일세포 RNA-seq 세포 유형 분류 프로젝트

## 1. 프로젝트 개요
- **생물학적 질문:** 시퀀싱 깊이(총 발현량)가 서로 다른 세포들의 원시 발현량(Raw UMI Count)을 정규화(Normalization)하면, 단순 개수 비교와 다른 세포 유형 판정 결과가 나올까?
- **분석 대상:** 생쥐(*Mus musculus*) 이자(Pancreas) 조직 단일세포 원시 카운트 데이터 (`NCBI GEO: GSE84133` 기반)
- **사용 유전자(4종):**
  - `Actb`: 하우스키핑 유전자 (품질 관리 QC 기준)
  - `Ins1`: 베타세포(Beta cell) 마커
  - `Gcg`: 알파세포(Alpha cell) 마커
  - `Amy2a`: 선방세포(Acinar cell) 마커

## 2. 배경지식 (Background Knowledge)

### ① 분자생물학적 배경지식
- **유전체 동일성과 차등적 유전자 발현 (Differential Gene Expression):**
  한 개체 내의 모든 체세포는 동일한 DNA(유전체)를 가지고 있지만, 세포마다 활성화된 전사 인자(Transcription Factor)와 후성유전학적 상태(염색질 응축 정도)가 달라 특정 유전자만 선택적으로 전사합니다. 그 결과 세포 안에 쌓이는 **mRNA의 종류와 양(전사체, Transcriptome)**이 달라지며, 이것이 세포의 정체성과 기능을 결정합니다.
- **Bulk RNA-seq vs 단일세포 RNA-seq (scRNA-seq):**
  - **Bulk RNA-seq:** 조직 전체를 한꺼번에 용해(Lysis)시켜 모든 세포의 mRNA 평균값을 측정하므로, 조직 내 세포 간 이질성(Heterogeneity)이나 소수 희귀 세포군의 고유 특성이 평균에 묻혀 사라집니다.
  - **scRNA-seq:** 미세유체역학(Microfluidics) 기술을 이용해 개별 세포를 미세 물방울(Droplet) 단위로 분리하고 고유한 **세포 바코드(Cell Barcode)**를 부착해 시퀀싱함으로써, 세포 하나하나의 전사체를 독립적으로 해독합니다.
- **생쥐(*Mus musculus*) 이자(Pancreas) 조직의 세포 구성:**
  이자 조직은 호르몬을 분비하는 내분비 조직(랑게르한스섬)과 소화 효소를 분비하는 외분비 조직이 공존하며, 세포 유형별 특이적 **마커 유전자(Marker Gene)**를 통해 구분할 수 있습니다.
  - `Ins1` (인슐린): 혈당을 낮추는 호르몬 분비 → **베타세포 (Beta cell)**
  - `Gcg` (글루카곤): 혈당을 높이는 호르몬 분비 → **알파세포 (Alpha cell)**
  - `Amy2a` (아밀레이스): 탄수화물 소화 효소 분비 → **선방세포 (Acinar cell)**
  - `Actb` (베타-액틴): 세포 골격을 구성하며 모든 세포에서 생명 유지를 위해 항상 발현되는 **하우스키핑 유전자(Housekeeping Gene)**로, 세포 생존 여부 및 데이터 품질 판별의 기준이 됩니다.

### ② 차세대 염기서열 분석(NGS) 및 데이터 전처리 핵심 개념
- **UMI (Unique Molecular Identifier, 고유 분자 식별자):**
  단일세포 하나에 들어 있는 mRNA 양은 극미량(피코그램 수준)이므로 시퀀싱 전 PCR 증폭 과정을 반드시 거칩니다. 이때 특정 mRNA 조각만 과도하게 복제되는 **PCR 증폭 편향(Amplification Bias)**을 막기 위해, 증폭 전 원래 mRNA 분자마다 무작위 짧은 염기서열(UMI)을 붙여둡니다. 따라서 **Raw UMI Count**는 단순 복제본 수가 아니라 실제 세포 안에 존재했던 원래 mRNA 분자의 개수를 의미합니다.
- **드롭아웃 (Dropout) 현상과 품질 관리 (QC, Quality Control):**
  단일세포 실험에서는 포획 효율의 한계나 역전사 실패로 인해 실제로는 발현된 유전자가 데이터상에서 `0`으로 기록되는 **드롭아웃(Dropout)** 현상이 빈번하게 일어납니다. 특히 모든 유전자 카운트가 `0`이거나 극도로 낮은 세포는 실험 과정에서 죽거나 손상된 세포(또는 빈 물방울)일 가능성이 높으므로, 분석 전 QC 단계에서 반드시 필터링해야 합니다.
- **시퀀싱 깊이(Sequencing Depth) 보정과 정규화 (Normalization):**
  세포마다 용해 효율과 시퀀싱 반응 정도가 달라 읽어낸 전체 UMI 총합(Library Size / Sequencing Depth)이 크게 차이 납니다. 절대 카운트(Raw Count)를 그대로 비교하면 단순히 시퀀싱이 많이 된 세포를 유전자 발현이 높은 세포로 오인하게 되므로, 세포별 총 발현량 대비 각 유전자가 차지하는 **상대 비율(%)**로 정규화하여 비교 기준을 통일해야 합니다.

$$\text{정규화 비율(\%)} = \left( \frac{\text{특정 유전자의 Raw UMI Count}}{\text{해당 세포의 전체 유전자 UMI Count 합계}} \right) \times 100$$

*(※ 실제 대규모 분석에서는 비율에 $10^6$을 곱한 **CPM(Counts Per Million)**을 구한 뒤, 극단적인 값의 편차를 줄이기 위해 자연로그를 취하는 **Log-normalization, $\ln(\text{CPM} + 1)$** 방식을 표준으로 사용합니다.)*

### ③ 파이썬 구현 및 검증 도구
- **`pandas`:** CSV 행렬 입출력(`read_csv`, `to_csv`), 가로 방향 합계 집계(`sum(axis=1)`), 행 단위 반복 처리(`iterrows`) 및 데이터 프레임 조작
- **조건문 및 예외 처리:** `if total == 0:` 분기를 통한 저품질 세포(빈 물방울/사멸 세포) 필터링, `raise ValueError`를 통한 비정상 음수 입력 차단
- **`assert` 자동 검증:** 손 계산으로 미리 산출한 정규화 비율 정답값 및 예외 케이스(0 입력 등) 처리 결과를 코드 실행 시 자동으로 대조 검증
- **`matplotlib.pyplot`:** 정규화 비율 결과를 막대그래프로 시각화하여 세포 유형별 마커 발현 패턴 비교

## 3. 주요 구현 기능
1. **데이터 전처리 (QC & Normalization):** 총 발현량이 0인 저품질 세포 필터링 및 시퀀싱 깊이 보정을 위한 세포별 정규화 비율(%) 계산
2. **세포 유형 자동 분류:** 정규화 비율이 가장 높은 마커 유전자(`Ins1`, `Gcg`, `Amy2a`)를 기준으로 세포 유형 자동 판별
3. **자동 검증 테스트 (`assert`):** 손 계산 기준값 및 예외 케이스(0 입력 등) 자동 검산
