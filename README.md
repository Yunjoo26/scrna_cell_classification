# 🧬 생쥐 이자(Pancreas) 단일세포 RNA-seq 세포 유형 분류 프로젝트

## 1. 프로젝트 개요
- **생물학적 질문:** 시퀀싱 깊이(총 발현량)가 서로 다른 세포들의 원시 발현량(Raw Read Count)을 정규화(Normalization)하면, 단순 개수 비교와 다른 세포 유형 판정 결과가 나올까?
- **분석 대상:** 생쥐(*Mus musculus*) 이자(Pancreas) 조직 단일세포 원시 카운트 데이터 (`NCBI GEO: GSE84133` 기반)
- **사용 유전자(4종):**
  - `Actb`: 하우스키핑 유전자 (품질 관리 QC 기준)
  - `Ins1`: 베타세포(Beta cell) 마커
  - `Gcg`: 알파세포(Alpha cell) 마커
  - `Amy2a`: 선방세포(Acinar cell) 마커

## 2. 배경지식 (Background Knowledge)

### ① 생물학적 배경지식 (『캠벨 생명과학』 연계)
- **유전체 동일성과 차등적 유전자 발현 (Differential Gene Expression):**
  한 개체 내의 모든 체세포는 동일한 DNA(유전체)를 가지고 있지만, 세포마다 작동하는 전사 인자와 염색질 상태가 달라 서로 다른 유전자만 선택적으로 전사합니다. 그 결과 세포 안에 쌓이는 **mRNA의 종류와 양(전사체, Transcriptome)**이 달라지며, 이것이 세포의 형태와 기능을 결정합니다.
- **Bulk RNA-seq vs 단일세포 RNA-seq (scRNA-seq):**
  - **Bulk RNA-seq:** 조직 전체를 한꺼번에 갈아 모든 세포의 mRNA 평균값을 측정하므로, 소수 세포군의 고유한 특성이 평균에 묻혀 사라집니다.
  - **scRNA-seq:** 개별 세포에 고유한 세포 바코드(Cell Barcode)를 붙여 시퀀싱함으로써, 세포 하나하나의 유전자 발현량을 분리해 측정합니다.
- **생쥐(*Mus musculus*) 이자(Pancreas) 조직의 세포 구성:**
  이자 조직 안에는 내분비 세포(랑게르한스섬)와 외분비 세포가 함께 존재하며, 각 세포에서만 특이적으로 강하게 발현되는 **마커 유전자(Marker Gene)**를 통해 정체를 판별합니다.
  - `Ins1` (인슐린): 혈당을 낮추는 호르몬 분비 → **베타세포 (Beta cell)**
  - `Gcg` (글루카곤): 혈당을 높이는 호르몬 분비 → **알파세포 (Alpha cell)**
  - `Amy2a` (아밀레이스): 소화 효소 분비 → **선방세포 (Acinar cell)**
  - `Actb` (베타-액틴): 모든 세포에서 생명 유지를 위해 공통으로 발현되는 **하우스키핑 유전자(Housekeeping Gene)**로, 데이터 품질 확인 기준으로 활용됩니다.

### ② 데이터 분석 및 전처리 원리
- **발현 행렬 (Count Matrix):** 각 세포에서 특정 유전자의 mRNA가 몇 번 읽혔는지 기록한 원시 정수(Raw Read Count) 표입니다.
- **품질 관리 (QC)와 드롭아웃 (Dropout):** 단일세포 시퀀싱 과정에서는 세포 손상이나 극미량 mRNA 포착 실패(드롭아웃 현상)로 인해 모든 유전자 발현량이 `0`으로 기록되는 저품질 세포가 발생합니다. 이를 사전에 필터링해야 나눗셈 오류(`ZeroDivisionError`)와 잘못된 분류를 막을 수 있습니다.
- **시퀀싱 깊이(Sequencing Depth) 보정과 정규화 (Normalization):** 세포마다 시퀀싱 효율이 달라 읽어낸 전체 mRNA 총합(Total Count)이 다릅니다. 따라서 절대 개수가 아닌, 세포별 총 발현량 대비 각 유전자가 차지하는 **상대 비율(%)**로 환산해 기준을 통일해야 세포 간 공정한 비교가 가능합니다.

$$\text{정규화 비율(\%)} = \left( \frac{\text{특정 유전자 발현량}}{\text{해당 세포의 전체 유전자 발현량 합계}} \right) \times 100$$

### ③ 파이썬 구현 및 검증 도구
- **`pandas`:** CSV 데이터 입출력(`read_csv`, `to_csv`), 가로 방향 합계 집계(`sum(axis=1)`), 행 순회(`iterrows`) 및 데이터 프레임 조작
- **조건문 및 예외 처리:** `if total == 0:` 분기를 통한 저품질 세포 필터링, `raise ValueError`를 통한 음수 입력 차단
- **`assert` 자동 검증:** 손 계산으로 미리 구한 정규화 비율 정답값 및 예외 케이스 처리 결과를 코드 실행 시 자동으로 대조 검증
- **`matplotlib.pyplot`:** 정규화 비율 결과를 막대그래프로 시각화하여 세포 유형별 발현 패턴 비교

## 3. 주요 구현 기능
1. **데이터 전처리 (QC & Normalization):** 총 발현량이 0인 저품질 세포 필터링 및 세포별 정규화 비율(%) 계산
2. **세포 유형 자동 분류:** 정규화 비율이 가장 높은 마커 유전자(`Ins1`, `Gcg`, `Amy2a`)를 기준으로 세포 유형 판별
3. **자동 검증 테스트 (`assert`):** 손 계산 기준값 및 예외 케이스(0 입력 등) 자동 검산
